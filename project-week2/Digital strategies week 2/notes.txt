Provided datasets
=================

** French MPs
Practices of MPs in France (collected by Ollion et al 2020): 23 variables, 569 MPs
Check codebook for details: FrenchMPs-Codebook.odt
Data: MPs2017.csv


** Human Freedom Index
Country-specific measures capturing state of human freedom, as conceptualized and documented by the Cato Institute.
Data available in csv format: hfi2008_2016.csv
Variable descriptions in separate file. Also check website for context and codes: https://www.cato.org/human-freedom-index/2018


** Measuring socialism
Country-specific data on policies etc. From: Joseph Nathan Cohen
Check provided script files available in the zip file
Data in provided csv file - also check codebook for details


** valkalkylator
Response data from individuals (respondents) and political parties, taking a stand on several questions.
Example data:
- How individuals have responded to each statement (agree/disagree, significance)
- How each party has responded to each statement (from lab)
- How far away each respondent is from each party (in terms of how they responded)
Data available as a .sqlite file. To generate the data frame(s) you want to work with, check the 'valkalk_extract_csv.R' file


** Valkompassen 2014
Politicians responding to another party affiliation test - also includes personal data
Details and codebook: Valkompass_TranslatedCategories.txt
Data: Valkompass2014_ShortRecoded_anon.csv
